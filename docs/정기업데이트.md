# 세부인 정기 업데이트 체크리스트

세부인에서 시간이 지나면 낡는 데이터와, 각각을 언제·어떻게 갱신하는지 정리한 문서입니다.
드리머가 "세부인 정기 업데이트 해줘"라고 하면 Claude는 이 문서를 먼저 읽고, 표의 **마지막 갱신**을 보고 밀린 항목부터 처리한 뒤 이 문서의 날짜도 함께 고칩니다.

정리일: 2026-10-22

## 항목별 메모

### 단지 관심도 TOP 20 (`interest.json`)
- **집계 규칙 전체는 `docs/관심도_검색량_집계방법.md`** 에 있습니다(검색어 만드는 법, 합산, 지수, 급증 판정, 노출 원칙).
- 요약: 단지마다 마을명·동·브랜드 조합 검색어(A, 최대 8개)와 번호 없는 브랜드 검색어(B)를 검색광고 키워드 도구로 조회해 합산, 가재마을5단지(2026년 10월) = 100 고정 지수, 상위 20개만 표시.
- 실행: `python3 tools/interest_rank.py --keys <keys.env> --dry`로 먼저 확인한 뒤 `--dry` 없이 돌리면 `interest.json`(`month`, `basis` 포함)이 갱신됩니다.
- 키는 드라이브 `radar_keys.env`를 받아 저장소 밖 `keys.env`로 저장(`chmod 600`)해서 씁니다. 키 파일과 원 자료 `interest_raw.json`은 커밋하지 않습니다.

### 시장지표 (`data.json`)
- `data.json`은 구글시트 「세종시 홈페이지」에서 하루 여러 번 자동으로 다시 만들어집니다. **data.json을 직접 고치면 덮이므로, 값은 반드시 시트에 넣습니다.** (회사 컴퓨터에서는 구글시트가 막혀 있어 집 컴퓨터에서 작업)
- 원자료는 KB부동산 월간 주택가격동향 엑셀입니다.
  - 평균매매가격: 「41.평균매매」 세종 아파트 열(만원, 반올림)
  - 평균전세가격: 「42.평균전세」 세종 아파트 열
  - 전세가율: 「28.아파트매매전세비」 세종특별자치시 열
  - ㎡당 지역별 가격: 「47.㎡당아파트평균매매」 → `(매월) 전국 m2당 매매가격` 탭
  - 상승률은 반올림한 만원 단위끼리 전월 대비, PIR·J-PIR은 평균매매·평균전세 ÷ 중위소득
- `main` 탭 입력법: 마지막 행(B~M)을 복사해 바로 아래에 붙여넣고 B(월)·C(평균매매)·E(평균전세)·J(전세가율)만 새 값으로 덮습니다. 상승률·PIR·J-PIR·Y 판정은 수식이라 자동 계산됩니다. 중위소득(G)은 바뀐 경우에만 고칩니다.
- 매매·전세가는 기존 행처럼 소수점 이하를 버린 값(예: 56,183.9 → 56183), 전세가율은 엑셀 원값을 그대로 넣습니다.
- 2026년 9월분: 56,183 / 26,498 / 50.39, 10-22 입력 완료.
- 2026년 10월분: 56,167 / 26,685 / 50.74, 10-26 입력 완료(main 120행, ㎡당 탭 121행).
- 화면의 "○년 ○월 갱신" 배지는 이 데이터의 마지막 달로 자동 표시됩니다.

### 국토부 원자료 (`data/molit/`)
- 매매: 직거래·해제 제외, 2021.11 계약분부터. 전월세: 갱신 계약은 시세 지표에서 제외.
- 최근 달은 신고 기한(계약 후 30일) 때문에 이후 건수가 늘어납니다. 갱신 때 직전 2개월도 다시 받습니다.

### 학업 환경 (`education.json`)
단지 정보 페이지의 "학업 환경" 블록. 세 지표는 합산하지 않고 따로 보여줍니다.

1. **학원 강도** (분기 1회)
   - 원천: 나이스 교육정보 개방포털 학원교습소정보, 세종시교육청(I10), 개원 상태, 분야 "입시·검정 및 보습" + "국제화".
   - 인증키 없는 API는 5건만 주므로, 포털의 데이터셋 시트 화면(크롬)에서 세종 전체를 받습니다.
   - 학원 주소의 건물명으로 네이버 지역검색(세부인 프록시)을 해 좌표를 잡고, 못 잡으면 법정동 중심 좌표를 씁니다.
   - 단지 좌표는 `transit.json`의 `data[단지][4..5]`. 단지 중심 반경 1km 학원 수 → 161개 단지 순위 5분위(1=상위 20%).
2. **학부모 관심 학교** (분기 1회)
   - 동지역 중학교별로 네이버 카페·블로그 최근 글(세부인 프록시, sort=date)을 모읍니다.
   - 학원 광고·과외·매물·분양 글과 다른 지역 동명 학교(원주 반곡중, 용인 양지중 등)를 빼고, 세종 맥락(세종·마을 이름)이 있는 글만 남깁니다. 중복 글은 하나로 칩니다.
   - 학교명 앞뒤에 긍정 표현이 붙은 언급 수 상위 4곳에 배지. 순위·하위는 노출하지 않습니다.
   - 카페 글은 API에 날짜가 없어 "최근 글 위주" 기준입니다.
3. **중학교 진학 실적** (연 1회)
   - 원천: 학교알리미 중학교 "졸업생의 진로 현황", 최근 3개년 공시 합산.
   - 진학률 = (과학고 + 외고·국제고 + 자사고) ÷ 졸업자. 자공고, 예고·체고, 마이스터고, 기타는 제외.
   - 동지역 평균 대비 통계적으로 뚜렷한 곳만 높음·낮음, 나머지는 보통(5분위로 나누지 않음).
   - 산울중처럼 졸업생이 없는 학교는 "자료 없음". 첫 졸업생이 나오면 반영합니다.
- 가까운 중학교: 단지 중심에서 직선거리 가까운 2곳. 세종 동지역은 학교군 선지원·근거리 배정이라 실제 배정과 다를 수 있다는 안내를 페이지 하단에 둡니다.
- 고등학교 교과 A비율은 학교별 출제 난이도 차이가 커서 쓰지 않기로 했습니다.

### 대중교통 강도·도달권
- `python3 tools/transit_strength.py <세종 버스운행현황.csv>` (기준: 단지 반경 500m, BRT 50% + 환승 없이 닿는 정류장 25% + 전체 운행 25%, 백분위 합산).
- 노선이 바뀌면 `bus_sejong.json`과 도달권 이미지(`images/reach`, `images/reach-wide`)도 다시 만듭니다.

### 단지 정보 (`complexes.json`)
- 장점 후기는 입주민이 불편해할 단점은 최소화하고, 온라인에서 명확히 확인되지 않는 하자 이력은 넣지 않으며, 출처 링크는 달지 않습니다.
- 새 단지가 입주하면 `complexes.json`에 더하고, `transit.json`·`education.json`도 같은 단지 이름으로 계산해야 페이지 블록이 나옵니다.
