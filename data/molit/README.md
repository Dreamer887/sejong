# 국토부 아파트 매매 실거래 원자료 (세종)

- 출처: 국토교통부 아파트 매매 실거래가 API (`RTMSDataSvcAptTrade`, LAWD_CD 36110)
- `세종_아파트매매_2021-11_2026-10.csv`: 계약월 2021.11 ~ 2026.10, 19,466건
  - 직거래·해제 거래 제외 (거래유형 항목이 2021.11 계약분부터 공개되어 이 달부터 수록)
  - `지역구분` 열로 동 지역 / 읍면(조치원·면 지역) 구분
  - 2026.10분은 신고 기한(계약 후 30일) 전이라 이후 추가될 수 있음
- 수집일: 2026-10-19

## 전월세 원자료

- 출처: 국토교통부 아파트 전월세 실거래가 API (`RTMSDataSvcAptRent`, LAWD_CD 36110)
- `세종_아파트전월세_2021-11_2026-10.csv`: 계약월 2021.11 ~ 2026.10, 97,716건 (동 지역 90,403건)
  - `월세(만원)`이 0이면 전세, `계약구분`은 신규·갱신(빈칸은 미기재)
  - 갱신 계약은 인상 상한 때문에 시세보다 낮게 찍히므로, 전세가율 등 시세 지표는 신규 계약만 쓴다
- 수집: `tools/fetch_molit_rent.py`, 수집일 2026-10-19
