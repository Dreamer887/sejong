휴대폰별 설정 방법

  1. 크롬이나 삼성 인터넷으로 이 페이지를 열어요.
    카카오톡·네이버 앱 안에서 열었다면 오른쪽 위 ⋮ → 다른 브라우저로 열기를 눌러주세요.
  2. 위의 🔔 알림 받기 버튼을 누르고, 뜨는 창에서 허용을 눌러요.
  3. 바로 "세부인 알림이 켜졌어요 ✅" 확인 알림이 오면 끝이에요.
확인 알림이 안 온다면
  • 휴대폰 설정 → 애플리케이션 → Chrome(또는 삼성 인터넷) → 알림이 켜져 있는지 확인해요.
  • 크롬 주소창 왼쪽 아이콘 → 권한 → 알림이 허용인지 확인해요. '차단'이면 허용으로 바꾼 뒤 이 페이지를 새로고침하세요.
  • 설정 → 배터리의 절전·잠자는 앱 목록에 크롬이 있으면 빼주세요. 오래 안 쓰면 알림이 늦게 올 수 있어요.
아이폰은 홈 화면에 세부인을 추가한 뒤 그 아이콘으로 열어야 알림을 켤 수 있어요. (iOS 16.4 이상)
  1. 사파리로 이 페이지(sebuin.com/alerts.html)를 열어요.
    카카오톡·네이버 앱 안에서 열었다면 아래 공유나 ⋯ → Safari로 열기를 눌러주세요.
  2. 화면 아래(또는 주소창 옆)의 공유 버튼 □↑을 눌러요.
  3. 목록을 내려 홈 화면에 추가를 누르고, 오른쪽 위 추가를 눌러요.
  4. 홈 화면에 생긴 세부인 아이콘을 눌러 열어요. 이 알림 페이지가 바로 열려요.
  5. 🔔 알림 받기 → 허용을 누르면 확인 알림이 와요.
확인 알림이 안 온다면
  • 설정 → 알림 → 세부인에서 알림 허용, 잠금 화면·배너가 켜져 있는지 확인해요.
  • 집중 모드(방해 금지·수면)가 켜져 있으면 알림이 숨겨질 수 있어요.
  • iOS 버전이 16.4보다 낮으면 설정 → 일반 → 소프트웨어 업데이트를 먼저 해주세요.

자주 묻는 질문

돈이 들거나 가입해야 하나요?

아니요. 무료이고 가입도 없어요. 휴대폰 브라우저의 기본 알림 기능을 쓰기 때문에 앱을 깔 필요도 없어요.

어떤 정보가 저장되나요?

알림을 보낼 기기 주소(브라우저가 만든 푸시 주소)와 고른 알림 종류만 저장해요. 이름·이메일·전화번호는 받지 않고, 알림을 끄면 바로 지워져요. 자세한 내용은 개인정보처리방침에 있어요.

실거래 알림은 언제 오나요?

국토교통부는 신고된 거래를 다음 날 공개해요. 세부인은 매일 아침 새로 공개된 세종 아파트 매매 거래를 모아서 7~8시쯤 보내드려요. 새로 공개된 거래가 없는 날은 보내지 않아요.

알림을 끄고 싶어요

이 페이지에서 이 기기에서 알림 끄기를 누르거나, 휴대폰 설정에서 브라우저(아이폰은 세부인)의 알림을 끄면 돼요.

휴대폰을 바꾸거나 브라우저 데이터를 지웠어요

알림은 기기·브라우저마다 따로 켜져요. 새 기기에서 이 페이지를 열어 다시 알림 받기를 눌러주세요.
